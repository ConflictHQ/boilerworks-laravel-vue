# Boilerworks Laravel + Vue

> Laravel 11 with Inertia.js and Vue 3 for full-stack Laravel ecosystem SPAs.

**Status:** Building

## Stack

| Layer | Technology |
|-------|-----------|
| Backend | Laravel 11 |
| Frontend | Vue 3 (Composition API) |
| Bridge | Inertia.js |
| Database | Postgres 16 |
| Cache | Redis 7 |
| Task Queue | Laravel Horizon |
| CSS | Tailwind CSS |
| Build | Vite |

## Features

- Laravel 11 with Inertia.js for seamless server-driven SPA
- Vue 3 with Composition API and TypeScript
- Laravel Horizon for queue monitoring and job management
- Session-based auth with Laravel Breeze and group-based RBAC
- Tailwind CSS with Vite
- Laravel Sanctum for API token management
- Docker Compose dev environment (Postgres, Redis, Mailpit)
- Comprehensive test suite with Pest
