## Stack

- **Backend**: Laravel 11
- **Frontend**: Vue 3 (Composition API) via Inertia.js
- **API**: Inertia.js (server-driven SPA)
- **ORM**: Eloquent
- **Jobs**: Laravel Horizon + Redis
